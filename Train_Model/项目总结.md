# Web漏洞攻击多分类检测系统 — 项目总结

> 本文档用于交给AI进行毕业论文核对，涵盖项目的完整技术细节。

---

## 一、项目概述

**项目名称：** Web漏洞攻击多分类检测系统（WebAttackDetector）

**项目性质：** 本科毕业设计，纯离线ML训练与评估流水线（无Web前端、无数据库、无API服务）

**核心任务：** 对HTTP请求参数进行5分类检测，识别正常流量和4种Web攻击类型

**技术路线：** 采用"传统机器学习 + 深度学习"双模型对比方案
- 模型一：TF-IDF特征 + LightGBM（梯度提升树）
- 模型二：字符级TextCNN（卷积神经网络）

---

## 二、数据集说明

### 2.1 数据来源

| 数据源 | 类型 | 说明 |
|--------|------|------|
| CSIC 2010 | 正常流量 | HTTP请求参数 |
| sqlmap | SQL注入 | 自动化SQL注入工具生成的payload |
| xssya | XSS攻击 | 跨站脚本攻击样本 |
| Vega Scanner | 命令注入/路径遍历 | 扫描器生成的攻击样本 |
| FuzzDB | 补充攻击样本 | 攻击字典库 |

### 2.2 分类标签（5类）

| 标签 | 含义 | 训练集数量 | 验证集数量 | 测试集数量 | 占比(训练集) |
|------|------|-----------|-----------|-----------|-------------|
| norm | 正常流量 | 10,296 | 2,574 | 6,434 | 62.1% |
| sqli | SQL注入 | 5,788 | 1,447 | 3,617 | 34.9% |
| xss | 跨站脚本 | 284 | 71 | 177 | 1.7% |
| path-traversal | 路径遍历 | 154 | 39 | 97 | 0.9% |
| cmdi | 命令注入 | 47 | 12 | 30 | 0.3% |

**总样本量：** 31,067条（训练集16,569 + 验证集4,143 + 测试集10,355）

**类别不平衡问题：** cmdi类仅47个训练样本（0.3%），与sqli类（5,788个）相差123倍。

### 2.3 数据划分策略

- 原始数据集 `payload_train.csv`（20,712条）通过**分层采样**（80/20，随机种子42）划分为：
  - `train_split.csv`（16,569条）— 训练集
  - `val_split.csv`（4,143条）— 验证集
- `payload_test.csv`（10,355条）作为**密封测试集**，训练过程中完全不可见
- CSV字段：`payload`（HTTP参数值）、`length`（长度）、`attack_type`（5分类标签）、`label`（二分类标签）

## 三、数据预处理

对原始payload文本执行以下预处理流水线：

1. **3轮URL解码** — 处理多层编码（如 `%2527` → `%27` → `'`）
2. **HTML实体还原** — `&lt;` → `<`，`&gt;` → `>`，`&amp;` → `&` 等
3. **转小写** — 统一大小写
4. **空白字符压缩** — 连续空白压缩为单个空格

## 四、模型一：TF-IDF + LightGBM

### 4.1 特征工程（共80,019维）

| 特征类型 | 维度 | 参数配置 |
|----------|------|----------|
| 字符级TF-IDF | 50,000 | analyzer=char_wb, ngram_range=(2,5), sublinear_tf=True |
| 词级TF-IDF | 30,000 | analyzer=word, ngram_range=(1,2), sublinear_tf=True |
| 手工统计特征 | 19 | 文本长度、特殊字符计数、攻击模式匹配等 |

**手工特征详情（19维）：**
- 文本长度
- 特殊字符计数：`'`、`"`、`<`、`>`、`/`、`\`、`(`
- 攻击模式指示：`--`、`/*`、`../`、`script`、`select`、`union`、`insert`、`drop`、`exec`
- 布尔正则匹配：`or`、`and`

### 4.2 模型超参数

```
learning_rate      = 0.05
num_leaves         = 127
min_child_samples  = 5
feature_fraction   = 0.8
bagging_fraction   = 0.8
bagging_freq       = 5
L1正则化           = 0.1
L2正则化           = 0.1
最大迭代轮数       = 500
早停轮数           = 30（验证集multi_logloss）
类别平衡样本权重   = 启用
```

### 4.3 训练结果

- **最佳迭代轮数：** 第310轮（第340轮触发早停）
- **测试集指标：**
  - Accuracy: 99.92%
  - Precision (macro): 97.84%
  - Recall (macro): 98.33%
  - F1 (macro): 98.08%

## 五、模型二：TextCNN（字符级）

### 5.1 网络架构

```
输入层：字符序列（长度200，截断/填充）
    ↓
Embedding层：词表大小97（ASCII 32-126 + PAD + UNK），嵌入维度64
    ↓
并行卷积层（4个）：
  - Conv1d(kernel_size=2, filters=128)
  - Conv1d(kernel_size=3, filters=128)
  - Conv1d(kernel_size=4, filters=128)
  - Conv1d(kernel_size=5, filters=128)
    ↓
自适应最大池化：每个卷积输出压缩为1个值
    ↓
拼接：4 × 128 = 512维
    ↓
Dropout(0.5)
    ↓
全连接层：Linear(512, 5) → 5分类输出
```

### 5.2 训练配置

```
序列长度           = 200
批大小             = 256
优化器             = Adam(lr=1e-3, weight_decay=1e-4)
学习率调度         = ReduceLROnPlateau(factor=0.5, patience=3, monitor=macro F1)
早停               = patience=7, monitor=验证集macro F1
损失函数           = CrossEntropyLoss（类别平衡权重）
最大训练轮数       = 30（实际在第20轮早停）
```

### 5.3 可复现性保障

- 所有随机种子固定为42（Python、NumPy、PyTorch、CUDA）
- `torch.backends.cudnn.deterministic = True`
- `torch.backends.cudnn.benchmark = False`
- DataLoader `worker_init_fn` 控制worker种子

### 5.4 训练结果

- **最佳epoch：** 第13轮（第20轮触发早停）
- **测试集指标：**
  - Accuracy: 99.91%
  - Precision (macro): 98.59%
  - Recall (macro): 97.56%
  - F1 (macro): 98.07%

## 九、训练流水线（train.py main函数，10步）

1. 加载预划分数据（train/val/test CSV）
2. 文本预处理（URL解码 → HTML实体还原 → 转小写 → 空白压缩）
3. 标签编码（LabelEncoder，仅在训练集fit）
4. 特征工程（TF-IDF字符+词级 + 19维手工特征 = 80,019维）
5. LightGBM训练（类别权重 + 早停）
6. LightGBM评估（验证集 + 测试集），保存模型和特征提取器
7. TextCNN训练（类别权重 + 学习率衰减 + 早停）
8. TextCNN评估（验证集 + 测试集）
9. 少数类分析（cmdi、path-traversal、xss详细指标）
10. 模型对比（CSV + 分组柱状图），保存训练日志

## 十、关键改进点（相比旧版本）

| 问题 | 旧版本 | 优化版本 |
|------|--------|----------|
| 数据泄露 | 用测试集做验证 | 严格划分train/val/test，测试集密封不可见 |
| 可复现性 | 无种子固定 | 所有随机种子固定为42，CUDA确定性模式 |
| 早停策略 | 无/简陋 | LightGBM: patience=30; TextCNN: patience=7 |
| 类别不平衡 | 未处理 | 两个模型均使用类别平衡样本权重 |
| 学习率调度 | 无 | TextCNN使用ReduceLROnPlateau |
