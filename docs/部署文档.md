# WAD 部署文档

## 概述

本文档详细说明如何部署 WAD (Web Attack Detection) 系统，包括开发环境和生产环境的部署方案。

---

## 一、环境要求

### 1.1 硬件要求

| 环境 | CPU | 内存 | 磁盘 | 说明 |
|------|-----|------|------|------|
| 开发环境 | 2 核+ | 4GB+ | 10GB+ | 本地开发测试 |
| 测试环境 | 4 核+ | 8GB+ | 50GB+ | 功能测试 |
| 生产环境 | 8 核+ | 16GB+ | 100GB+ | 生产部署 |

### 1.2 软件要求

| 软件 | 版本 | 说明 |
|------|------|------|
| Python | 3.9+ | 推荐 3.9.25 |
| pip | 21.0+ | Python 包管理器 |
| Git | 2.30+ | 版本控制 |
| Nginx | 1.20+ | 反向代理（生产环境） |

### 1.3 操作系统

- **推荐**：Ubuntu 20.04/22.04 LTS、CentOS 7/8、Debian 10/11
- **支持**：Windows 10/11、macOS 10.15+

## 二、快速部署（开发环境）

### 2.1 克隆项目

```bash
git clone https://github.com/your-username/Web-Attack-Detection-System-HttpParamsDataset.git
cd Web-Attack-Detection-System-HttpParamsDataset
```

### 2.2 创建虚拟环境

```bash
# 使用 venv
python -m venv venv

# 激活虚拟环境
# Linux/macOS
source venv/bin/activate
# Windows
venv\Scripts\activate

# 或使用 conda
conda create -n wad python=3.9
conda activate wad
```

### 2.3 安装依赖

```bash
# 安装所有依赖
make install

# 或分别安装
pip install -r Train_Model/requirements.txt
pip install -r Web_Frontend/requirements.txt
pip install -r Inference_API/requirements.txt
```

### 2.4 启动服务

```bash
# 方式一：使用 Makefile
make start

# 方式二：手动启动
# 终端 1：启动推理服务
cd Inference_API
python api_server.py

# 终端 2：启动 Web 前端
cd Web_Frontend
python app.py
```

### 2.5 访问服务

- **Web 前端**：http://localhost:5000
- **推理服务**：http://localhost:9000
- **API 文档**：http://localhost:9000/docs

## 三、生产环境部署

### 3.1 系统配置

**1. 更新系统**
```bash
sudo apt-get update
sudo apt-get upgrade -y
```

**2. 安装依赖**
```bash
sudo apt-get install -y \
    python3 \
    python3-pip \
    python3-venv \
    nginx \
    supervisor \
    git
```

**3. 创建用户**
```bash
sudo useradd -m -s /bin/bash wad
sudo passwd wad
```

### 3.2 部署应用

**1. 克隆项目**
```bash
sudo su - wad
git clone https://github.com/your-username/Web-Attack-Detection-System-HttpParamsDataset.git
cd Web-Attack-Detection-System-HttpParamsDataset
```

**2. 创建虚拟环境**
```bash
python3 -m venv venv
source venv/bin/activate
```

**3. 安装依赖**
```bash
pip install --upgrade pip
pip install -r Train_Model/requirements.txt
pip install -r Web_Frontend/requirements.txt
pip install -r Inference_API/requirements.txt
pip install gunicorn
```

### 3.3 配置 Gunicorn

**1. 创建 Gunicorn 配置文件**
```bash
cat > gunicorn_config.py << EOF
# Gunicorn 配置文件
bind = "127.0.0.1:5000"
workers = 4
worker_class = "sync"
timeout = 120
keepalive = 5
max_requests = 1000
max_requests_jitter = 50
accesslog = "/var/log/wad/access.log"
errorlog = "/var/log/wad/error.log"
loglevel = "info"
EOF
```

**2. 创建日志目录**
```bash
sudo mkdir -p /var/log/wad
sudo chown wad:wad /var/log/wad
```

**3. 测试 Gunicorn**
```bash
cd Web_Frontend
gunicorn -c ../gunicorn_config.py "app:create_app()"
```

### 3.4 配置 Supervisor

**1. 创建 Supervisor 配置文件**
```bash
sudo cat > /etc/supervisor/conf.d/wad-inference.conf << EOF
[program:wad-inference]
command=/home/wad/Web-Attack-Detection-System-HttpParamsDataset/venv/bin/python api_server.py
directory=/home/wad/Web-Attack-Detection-System-HttpParamsDataset/Inference_API
user=wad
autostart=true
autorestart=true
redirect_stderr=true
stdout_logfile=/var/log/wad/inference.log
environment=PYTHONUNBUFFERED="1"
EOF
```

```bash
sudo cat > /etc/supervisor/conf.d/wad-web.conf << EOF
[program:wad-web]
command=/home/wad/Web-Attack-Detection-System-HttpParamsDataset/venv/bin/gunicorn -c /home/wad/Web-Attack-Detection-System-HttpParamsDataset/gunicorn_config.py "app:create_app()"
directory=/home/wad/Web-Attack-Detection-System-HttpParamsDataset/Web_Frontend
user=wad
autostart=true
autorestart=true
redirect_stderr=true
stdout_logfile=/var/log/wad/web.log
environment=PYTHONUNBUFFERED="1"
EOF
```

**2. 启动服务**
```bash
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start all
```

**3. 查看状态**
```bash
sudo supervisorctl status
```

### 3.5 配置 Nginx

**1. 创建 Nginx 配置文件**
```bash
sudo cat > /etc/nginx/sites-available/wad << EOF
server {
    listen 80;
    server_name your-domain.com;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # Web 前端
    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host \$host;
        proxy_set_header X-Real-IP \$remote_addr;
        proxy_set_header X-Forwarded-For \$proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto \$scheme;
        
        # 超时配置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 静态文件缓存
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|pdf|txt)$ {
        proxy_pass http://127.0.0.1:5000;
        expires 1d;
        add_header Cache-Control "public, immutable";
    }

    # 推理服务（可选，用于直接访问）
    location /api/inference/ {
        proxy_pass http://127.0.0.1:9000/;
        proxy_set_header Host \$host;
        proxy_set_header X-Real-IP \$remote_addr;
        proxy_set_header X-Forwarded-For \$proxy_add_x_forwarded_for;
    }

    # 健康检查
    location /health {
        access_log off;
        return 200 "healthy\n";
        add_header Content-Type text/plain;
    }

    # 错误页面
    error_page 500 502 503 504 /50x.html;
    location = /50x.html {
        root /usr/share/nginx/html;
    }
}
EOF
```

**2. 启用配置**
```bash
sudo ln -s /etc/nginx/sites-available/wad /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 3.6 配置 HTTPS（可选）

**1. 安装 Certbot**
```bash
sudo apt-get install certbot python3-certbot-nginx
```

**2. 获取证书**
```bash
sudo certbot --nginx -d your-domain.com
```

**3. 自动续期**
```bash
sudo crontab -e
# 添加以下行
0 12 * * * /usr/bin/certbot renew --quiet
```

## 四、监控与日志

### 4.1 日志配置

**应用日志位置**
```
/var/log/wad/
├── inference.log    # 推理服务日志
├── web.log         # Web 前端日志
├── access.log      # 访问日志
└── error.log       # 错误日志
```

**查看日志**
```bash
# 实时查看日志
tail -f /var/log/wad/inference.log
tail -f /var/log/wad/web.log

# 查看 Supervisor 日志
sudo supervisorctl tail -f wad-inference
sudo supervisorctl tail -f wad-web
```

### 4.2 监控脚本

**创建健康检查脚本**
```bash
cat > /home/wad/check_health.sh << EOF
#!/bin/bash

# 检查推理服务
if curl -s http://localhost:9000/health > /dev/null; then
    echo "推理服务正常"
else
    echo "推理服务异常"
    sudo supervisorctl restart wad-inference
fi

# 检查 Web 前端
if curl -s http://localhost:5000 > /dev/null; then
    echo "Web 前端正常"
else
    echo "Web 前端异常"
    sudo supervisorctl restart wad-web
fi
EOF

chmod +x /home/wad/check_health.sh
```

**设置定时任务**
```bash
crontab -e
# 添加以下行（每 5 分钟检查一次）
*/5 * * * * /home/wad/check_health.sh >> /var/log/wad/health.log 2>&1
```

## 五、备份与恢复

### 5.1 备份策略

**1. 数据库备份**
```bash
# 创建备份脚本
cat > /home/wad/backup_db.sh << EOF
#!/bin/bash

BACKUP_DIR="/home/wad/backups"
DATE=\$(date +%Y%m%d_%H%M%S)

# 创建备份目录
mkdir -p \$BACKUP_DIR

# 备份 SQLite 数据库
cp /home/wad/Web-Attack-Detection-System-HttpParamsDataset/Web_Frontend/instance/wad.db \\
   \$BACKUP_DIR/wad_\$DATE.db

# 删除 30 天前的备份
find \$BACKUP_DIR -name "*.db" -mtime +30 -delete

echo "备份完成: wad_\$DATE.db"
EOF

chmod +x /home/wad/backup_db.sh
```

**2. 设置定时备份**
```bash
crontab -e
# 添加以下行（每天凌晨 2 点备份）
0 2 * * * /home/wad/backup_db.sh >> /var/log/wad/backup.log 2>&1
```

### 5.2 恢复数据

```bash
# 停止服务
sudo supervisorctl stop wad-web

# 恢复数据库
cp /home/wad/backups/wad_20240101_020000.db \\
   /home/wad/Web-Attack-Detection-System-HttpParamsDataset/Web_Frontend/instance/wad.db

# 启动服务
sudo supervisorctl start wad-web
```

## 六、故障排除

### 6.1 常见问题

**Q1: 服务无法启动**
```bash
# 检查日志
sudo supervisorctl tail -f wad-inference
sudo supervisorctl tail -f wad-web

# 检查端口占用
sudo netstat -tlnp | grep :5000
sudo netstat -tlnp | grep :9000

# 检查权限
ls -la /home/wad/Web-Attack-Detection-System-HttpParamsDataset/
```

**Q2: 模型加载失败**
```bash
# 检查模型文件
ls -la Inference_API/outputs/

# 检查依赖
pip list | grep -E "torch|lightgbm|scikit-learn"
```

**Q3: 内存不足**
```bash
# 查看内存使用
free -h

# 减少 Gunicorn workers
# 编辑 gunicorn_config.py
workers = 2  # 减少 worker 数量
```

**Q4: 磁盘空间不足**
```bash
# 查看磁盘使用
df -h

# 清理日志
sudo find /var/log/wad -name "*.log" -mtime +7 -delete
```

### 6.2 性能优化

**1. 优化 Gunicorn**
```python
# gunicorn_config.py
workers = multiprocessing.cpu_count() * 2 + 1
worker_class = "gthread"
threads = 2
```

**2. 优化 Nginx**
```nginx
# nginx.conf
worker_processes auto;
worker_connections 1024;

# 启用 gzip
gzip on;
gzip_types text/plain text/css application/json application/javascript;
```

**3. 优化系统**
```bash
# 增加文件描述符限制
sudo cat >> /etc/security/limits.conf << EOF
wad soft nofile 65536
wad hard nofile 65536
EOF

# 优化内核参数
sudo cat >> /etc/sysctl.conf << EOF
net.core.somaxconn = 65535
net.ipv4.tcp_max_syn_backlog = 65535
EOF
sudo sysctl -p
```

## 七、安全加固

### 7.1 系统安全

**1. 更新系统**
```bash
sudo apt-get update
sudo apt-get upgrade -y
```

**2. 配置防火墙**
```bash
# 安装 UFW
sudo apt-get install ufw

# 配置规则
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow ssh
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# 启用防火墙
sudo ufw enable
```

**3. 禁用 root 登录**
```bash
sudo sed -i 's/PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config
sudo systemctl restart sshd
```

### 7.2 应用安全

**1. 配置 HTTPS**
```bash
# 使用 Let's Encrypt
sudo certbot --nginx -d your-domain.com
```

**2. 配置 CORS**
```python
# 限制允许的域名
CORS(app, resources={
    r"/api/*": {
        "origins": ["https://your-domain.com"],
        "methods": ["GET", "POST"],
        "allow_headers": ["Content-Type"]
    }
})
```

**3. 配置速率限制**
```python
# 使用 Flask-Limiter
from flask_limiter import Limiter
from flask_limiter.util import get_remote_address

limiter = Limiter(
    app,
    key_func=get_remote_address,
    default_limits=["100 per hour"]
)
```
