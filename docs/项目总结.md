# WAD 项目总结

## 一、项目概述

### 1.1 项目背景

随着互联网的快速发展，Web 应用面临的安全威胁日益严重。SQL 注入、XSS 跨站脚本、命令注入、路径穿越等攻击手段不断演变，传统的基于规则的检测方法已难以应对。本项目旨在利用机器学习技术，构建一个高效、准确的 Web 攻击检测系统。

### 1.2 项目目标

1. **高准确率**：在 HttpParamsDataset 数据集上实现 99.9%+ 的检测准确率
2. **多分类检测**：支持 5 分类检测（正常流量 + 4 种攻击类型）
3. **双模型对比**：提供 LightGBM 和 TextCNN 两种模型方案
4. **实用性强**：提供完整的 Web 界面和 API 接口
5. **易于部署**：支持传统部署方式

### 1.3 项目成果

- **模型性能**：LightGBM 和 TextCNN 均达到 99.9%+ 准确率
- **系统功能**：单条检测、批量检测、HTTP 解析、AI 分析、历史记录、统计看板
- **技术架构**：前后端分离、云端 API 推理、支持扩展

**数据来源**：
- CSIC 2010 数据集（正常流量）

- FuzzDB（补充攻击样本）

### 3.2 数据预处理

```python
def preprocess(text):
    # 1. 3 轮 URL 解码（处理多层编码）
    for _ in range(3):
        decoded = unquote(text)
        if decoded == text:
            break
        text = decoded
    
    # 2. HTML 实体还原
    text = text.replace("&lt;", "<")
              .replace("&gt;", ">")
              .replace("&amp;", "&")
              .replace("&quot;", '"')
              .replace("&#039;", "'")
    
    # 3. 转小写
    text = text.lower()
    
    # 4. 压缩空白字符
    text = re.sub(r"\s+", " ", text).strip()
    
    return text
```

### 3.3 LightGBM 模型

#### 特征工程（80,019 维）

| 特征类型 | 维度 | 参数配置 |
|----------|------|----------|
| 字符级 TF-IDF | 50,000 | analyzer=char_wb, ngram_range=(2,5) |
| 词级 TF-IDF | 30,000 | analyzer=word, ngram_range=(1,2) |
| 手工统计特征 | 19 | 特殊字符计数、攻击模式匹配等 |

#### 手工统计特征（19 维）

```python
# 文本长度
len(text)

# 特殊字符计数
text.count("'"), text.count('"'), text.count("<"),
text.count(">"), text.count("/"), text.count("\\"),
text.count("(")

# 攻击模式指示
text.count("--"), text.count("/*"), text.count("../"),
text.count("script"), text.count("select"),
text.count("union"), text.count("insert"),
text.count("drop"), text.count("exec")

# 布尔正则匹配
int(bool(re.search(r"\bor\b", text))),
int(bool(re.search(r"\band\b", text)))
```

### 3.4 TextCNN 模型

#### 网络架构

```
输入层：字符序列（长度 200，截断/填充）
    │
    ▼
Embedding 层：词表大小 97（ASCII 32-126 + PAD + UNK）
              嵌入维度 64
    │
    ▼
并行卷积层（4 个）：
  - Conv1d(kernel_size=2, filters=128)
  - Conv1d(kernel_size=3, filters=128)
  - Conv1d(kernel_size=4, filters=128)
  - Conv1d(kernel_size=5, filters=128)
    │
    ▼
自适应最大池化：每个卷积输出压缩为 1 个值
    │
    ▼
拼接：4 × 128 = 512 维
    │
    ▼
Dropout(0.5)
    │
    ▼
全连接层：Linear(512, 5) → 5 分类输出
```

## 四、系统功能

### 4.1 单条检测

- 输入单个 Payload
- 实时返回检测结果
- 显示攻击类型、置信度、概率分布
- 支持 LightGBM 和 TextCNN 模型选择

### 4.2 批量检测

- 支持手动输入多个 Payload
- 支持上传 txt/csv 文件
- 最多支持 500 条批量检测
- 支持导出检测结果 CSV

### 4.3 HTTP 解析

- 支持 Burp Suite 格式 HTTP 报文
- 自动提取所有参数（GET/POST/Cookie/Header）
- 解析 URL 编码参数
- 批量检测提取的参数

### 4.4 AI 深度分析

- 接入大语言模型 API（LongCat/豆包/DeepSeek）
- 对检测结果进行攻击原理解析
- 提供防御建议
- 支持多种 LLM 服务

### 4.5 历史记录

- SQLite 持久化存储
- 支持多维筛选（模型、类型、时间）
- 支持分页浏览
- 支持单条删除

### 4.6 统计看板

- 检测数量 KPI
- 攻击类型饼图
- 7 天趋势折线图
- 模型使用分布
- 模型性能评估
